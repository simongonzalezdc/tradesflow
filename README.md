# TradesFlow

Portfolio prototype for asset-heavy field-service businesses: customers, scheduled work, equipment history, service notes, deficiencies, and billing handoffs in one workspace.

**Who it is for:** people evaluating a field-service operating model (demo/prototype), not a multi-tenant SaaS claim.

**What you get:** app source with a focused domain model (users, businesses, appointments, invoices, equipment passport, service history, price book, notifications, consent).

## Quick start

```bash
git clone https://github.com/simongonzalezdc/tradesflow.git
cd tradesflow
# install and run via package scripts / README notes in-tree (Node stack)
```
